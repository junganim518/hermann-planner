개인정보처리방침

최종 수정일: 2026년 9월 18일

Hermann Planner(이하 "본 앱")는 개발자 본인이 개인적으로 사용하기 위해 만든 Windows 데스크탑 위젯 애플리케이션입니다. 본 개인정보처리방침은 본 앱이 Google 계정 정보를 어떻게 다루는지 설명하기 위해 작성되었습니다.

본 앱은 일반 사용자를 대상으로 배포되는 서비스가 아니며, 개발자 본인의 개인 용도로만 사용됩니다. Google OAuth 프로덕션 검증 절차를 위해 본 문서를 게시합니다.

1. 수집하는 정보 및 이용 목적

본 앱은 Google Calendar API 및 Google Tasks API를 통해 사용자 본인의 Google 계정에 저장된 다음 정보에 접근합니다.

  • Google Calendar의 일정(제목, 시간, 설명 등)을 조회, 추가, 수정, 삭제
  • Google Tasks의 할일 목록 항목을 조회, 추가, 수정, 삭제

이 정보는 오직 사용자가 데스크탑 위젯 화면에서 자신의 일정과 할일을 확인하고 관리할 수 있도록 하는 목적으로만 사용됩니다.

2. 데이터 저장 및 전송

  • 본 앱은 사용자의 로컬 컴퓨터에서 실행되며, 수집된 데이터는 로컬 컴퓨터와 Google 서버 간의 통신(Google API 호출)에만 사용됩니다.
  • 본 앱을 운영하기 위한 별도의 외부 서버는 존재하지 않습니다.
  • Google 계정 인증 정보(토큰)는 사용자의 로컬 컴퓨터에만 저장되며, 외부로 전송되지 않습니다.

3. 제3자 제공 및 광고 이용

  • 본 앱은 수집하거나 접근한 어떠한 개인정보도 제3자와 공유하지 않습니다.
  • 본 앱은 광고를 포함하지 않으며, 수집된 정보를 광고 목적으로 이용하지 않습니다.
  • 수집된 정보를 판매하거나 분석 목적의 외부 서비스에 전달하지 않습니다.

4. 데이터 보관 및 삭제

본 앱이 접근한 캘린더 및 할일 데이터는 로컬 컴퓨터에서만 표시되며, 별도로 영구 저장하지 않습니다. 사용자가 Google 계정 설정에서 언제든지 본 앱의 접근 권한을 해제할 수 있으며, 권한 해제 시 더 이상 데이터에 접근하지 않습니다.
