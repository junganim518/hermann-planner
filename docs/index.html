Hermann Planner

Windows 데스크탑용 캘린더 & 할일 위젯

Hermann Planner는 Google Calendar와 Google Tasks를 데스크탑 화면에서 바로 확인하고 관리할 수 있도록 만든 개인용 위젯 애플리케이션입니다.

주요 기능

  • Google Calendar 일정 조회 및 관리
  • Google Tasks 할일 목록 조회 및 관리
  • 데스크탑 화면에 상시 표시되는 위젯 형태
  • 일정 자동 새로고침 및 수동 새로고침 지원
